# Real-time Attendance Monitoring 
A Python-based application using Tkinter for GUI to capture and monitor real-time attendance efficiently. This system is ideal for classrooms, offices, or events to track individual attendance using an intuitive interface.

📌 Features
📷 Real-time attendance capture (camera or manual input)

🧑‍💻 Simple and clean GUI built with Tkinter

📅 Date-wise attendance tracking

🧾 CSV/Excel-based attendance logs

🔒 Admin login (optional security)

✅ Easy to scale or customize

🛠️ Technologies Used
Component	Description
Python	Core programming language
Tkinter	GUI library for the desktop interface
OpenCV (Optional)	For face detection and camera input (if used)
Pandas / CSV	Attendance data storage and processing
Datetime	For timestamping entries

🚀 How to Run the Project
1 Clone the Repository

git clone https://github.com/your-username/real-time-attendance.git
cd real-time-attendance

2 Install Dependencies
pip install -r requirements.txt

3 Run the Application

python main.py
